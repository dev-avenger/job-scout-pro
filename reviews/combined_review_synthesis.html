Critical Missing Features

Every reviewer independently identified these gaps as more important than most features already in the spec:

CAPTCHA and Anti-Bot Handling

Flagged by 8/8 reviewers

Workday, Greenhouse, Lever, and LinkedIn use PerimeterX, Cloudflare Turnstile, and reCAPTCHA. Without a strategy, 60%+ of applications fail silently. Need: 2Captcha/Anti-Captcha API, residential proxy rotation, browser fingerprint randomization, or human-in-the-loop fallback.

Error Recovery and Retry Logic

Flagged by 8/8 reviewers

The spec only describes happy-path scenarios. Missing: exponential backoff, dead-letter queues, partial form recovery, screenshot-on-failure, failure classification (retryable vs. terminal), and user notification for terminal failures.

Onboarding and Trust-Building Flow

Flagged by 7/8 reviewers

No first-run experience specified. Users need: guided setup wizard, dry-run/sandbox mode, example application previews, progressive trust escalation (forced Guided mode for first N applications), and a "quick start" path.

Legal/ToS Compliance Framework

Flagged by 7/8 reviewers

Missing: explicit strategy per platform (API vs. automation vs. off-limits), CAN-SPAM compliance for outreach, GDPR data export, ToS violation disclosure to users, jurisdiction-specific rules.

LLM Cost Management

Flagged by 6/8 reviewers

No cost controls. At 20+ applications/day with GPT-4 class models, users face $5-50/week. Need: per-application budgets, per-task model routing (cheap for extraction, expensive for writing), daily spend caps, cost estimates before runs.

Observability and Monitoring

Flagged by 6/8 reviewers

No operational monitoring for the developer. Need: error rate dashboards, portal health metrics, automation success rates, LLM spend tracking, alerting when systems fail silently.

05

Architecture Red Flags

Full Autopilot vs. No Hallucination Contradiction

The spec promises "zero human involvement" AND "never fabricates profile data." If the agent encounters an unknown question, it must either hallucinate (breaking trust) or pause (breaking autopilot).

Consensus fix: Mandatory onboarding in Guided mode. Full Autopilot only after 30-50+ supervised applications calibrate quality.

LinkedIn Automation = Existential Risk

7/8 reviewers flagged this. LinkedIn actively detects and bans automation. If user accounts get flagged, press coverage frames the product as a scam. One "App gets users' LinkedIn banned" headline kills the product.

Consensus fix: Cut all LinkedIn automation. Keep only profile optimization recommendations (no automation) and connection-surfacing (read-only).

Server-Side Credential Storage

Storing portal passwords server-side violates every platform's ToS and creates breach liability. No competitor does this — they all use browser extensions with local storage.

Consensus fix: Browser extension architecture for form filling. OAuth where available. Server-side only with explicit risk disclosure + proper key management.

Browser Automation Fragility

Form mapping breaks when portals update. Dynamic IDs, shadow DOM, nested iframes, JS-rendered fields. Workday alone has tens of thousands of unique instances.

Consensus fixes: LLM-based runtime DOM analysis (Gemini), browser extension as primary (DeepSeek/Meta), degradation strategy (Claude), cache 30 days + re-learn on failure (KIMI).

Multi-Agent Overkill

7 specialized agents is microservices complexity for a solo developer. Debugging inter-agent communication will consume more time than building the product.

Consensus fix: Modular monolith with clear service boundaries. Add agent separation later if needed.
